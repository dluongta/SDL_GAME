# SDL Game - Water Pipe
## Introduction

Water Pipe is a puzzle game developed using C++, BFS Algorithm and the SDL Library.

The main objective of the game is to rotate pipe pieces and connect them into a complete pipeline, allowing water to flow from the source to the destinations.

## How to Play
Use the left mouse button to rotate pipe pieces.
Connect all pipe pieces to create a continuous path.
Make sure the pipes are connected in the correct direction.
When the pipeline is completed, water will flow through the pipes.
The player wins when the water successfully reaches all water pipe destinations.

## Installation
Open SDLGame.exe file.
